# 语义抽象增强方案（借鉴 TimeSRL & SensorLM）

> 对应论文第七章。导师建议："You can draw inspirations from these papers."
> 两篇论文：SensorLM（层次化 caption）、TimeSRL（语义瓶颈 + RL）

## 一、理论动机

### SensorLM：层次化传感器描述
SensorLM 把传感器信号转成**三层语言描述**，让 LLM 理解生理信号：
1. **统计层**（statistical）：均值、标准差、范围
2. **结构层**（structural）：趋势、峰值时刻、波动模式
3. **语义层**（semantic）：生理状态推断（如"睡眠""运动"）

### TimeSRL：语义瓶颈
TimeSRL 的两阶段框架：
1. **抽象阶段**：把原始时间序列转成自然语言行为描述（语义瓶颈）
2. **推断阶段**：仅凭语义描述做下游预测
- 核心发现：语义瓶颈强制模型丢弃噪声、保留本质，从而提升**跨数据集泛化**

## 二、在 PPG-BP 任务上的应用

### 方法 1：层次化 PPG 描述（SensorLM 式）

把 55 维特征中关键生理量，按医学知识映射为三层语言：

| 层 | 示例 |
|----|------|
| 统计层 | "心率 72 bpm，平均脉宽 280ms" |
| 结构层 | "收缩峰幅值稳定，重搏切迹清晰，APG b/a 为 -0.35" |
| 语义层 | "提示中等动脉僵硬度、正常血管阻力" |

**规则映射**（医学依据）：
- 心率 HR：<60 偏慢 / 60–100 正常 / >100 偏快
- 增强指数 AIx：<60 低僵硬度 / 60–80 中等 / >80 高僵硬度
- APG b/a：<−0.4 阻力低 / −0.4~−0.2 正常 / >−0.2 阻力高
- 上升时间：反映心肌收缩力

### 方法 2：语义瓶颈（TimeSRL 式，两阶段）

```
阶段一（抽象）：LLM 输入 55 维特征 → 输出 PPG 语义摘要
  "该受试者 HR 72，血管僵硬度中等，血管阻力正常，
   综合推断血压处于正常偏高范围"

阶段二（推断）：LLM 仅凭语义摘要（不给数值）→ 预测 SBP/DBP
```

**研究问题**：语义摘要是否保留了足够的 BP 预测信息？
（对应 TimeSRL 的"语义瓶颈"检验）

## 三、实验设计

### 实验 A：层次化描述增强 Few-shot（方法 1）

- 基线：few-shot K=5 纯数值（已跑，SBP 12.2 / DBP 7.4）
- 增强：few-shot K=5，每个样本的数值特征**替换为层次化描述**
- 对比：纯数值 vs 数值+语义 vs 纯语义

### 实验 B：语义瓶颈两阶段（方法 2）

- 阶段一：对每个测试样本，LLM 生成语义摘要
- 阶段二：few-shot 校准（K=5），但特征只用语义摘要
- 对比：语义瓶颈下的预测精度 vs 纯数值

### 预期结果（论文叙事）

- 若语义描述不显著劣于数值 → 说明语义层保留了关键生理信息（SensorLM 论点）
- 若语义瓶颈下跨受试者泛化提升 → 验证 TimeSRL 的核心主张
